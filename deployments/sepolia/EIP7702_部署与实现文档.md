## 2. EIP-7702 批量存款实现

### 背景

EIP-7702 允许 EOA 将其执行逻辑委托给智能合约。在 Sepolia 测试网上，MetaMask (>= 12.7) 支持通过 `wallet_sendCalls` API 自动发起 type-4 EIP-7702 授权交易，将 `approve` + `deposit` 两步操作封装为一次原子交易。

### 前端交互流程

1. 用户输入存款金额 → 点击 **"一键授权+存款"** 按钮
2. 前端调用 `wallet_sendCalls` 传入两个调用：
   - `BaseERC20.approve(TokenBank, amount)`
   - `TokenBank.deposit(amount)`
3. MetaMask 弹出一次签名确认（EIP-7702 授权签名）
4. MetaMask 发送 type-4 交易，链上原子执行两步操作
5. 无需单独授权，一次签名完成

### 核心代码 (`handleEIP7702Deposit`)

```typescript
// 1. 编码 approve 和 deposit 调用
const approveCalldata = encodeFunctionData({
  abi: baseErc20Abi, functionName: 'approve',
  args: [TOKEN_BANK_ADDRESS, parsedAmount],
});
const depositCalldata = encodeFunctionData({
  abi: tokenBankAbi, functionName: 'deposit',
  args: [parsedAmount],
});

// 2. 通过 wallet_sendCalls 发送批量原子交易
const result = await ethereum.request({
  method: 'wallet_sendCalls',
  params: [{
    version: '2.0.0',
    chainId: chainIdHex,
    from: address,
    atomicRequired: true,
    calls: [
      { to: TOKEN_ADDRESS,      data: approveCalldata, value: '0x0' },
      { to: TOKEN_BANK_ADDRESS, data: depositCalldata, value: '0x0' },
    ],
  }],
});

// 3. 轮询 wallet_getCallsStatus 等待确认
const poll = setInterval(async () => {
  const status = await ethereum.request({
    method: 'wallet_getCallsStatus', params: [result.id],
  });
  // status 200 = 成功, >= 400 = 失败
}, 2000);
```

### 技术要点

| 项目 | 说明 |
|------|------|
| **API** | `wallet_sendCalls` (EIP-5792) |
| **交易类型** | type-4 EIP-7702 授权交易 |
| **原子性** | `atomicRequired: true` — 两步同时成功或同时回滚 |
| **底层** | MetaMask 自动使用 Delegator 合约 (`0x63c0...`) 作为 EOA 委托目标 |
| **签名** | 用户仅需一次签名（7702 授权签名） |

### 探索过程与结论

1. **方案 A：直接调用 Delegator 合约** — 失败。Delegator (`0x63c0...`) 有 EntryPoint 门禁（`msg.sender` 必须是 EntryPoint 或自身），未委托的 EOA 直接调用会 revert，MetaMask 模拟失败导致确认按钮灰色无法点击。

2. **方案 B：`capabilities.delegation` 显式指定** — 不可用。MetaMask 当前版本不支持在 `wallet_sendCalls` 中传入 `capabilities.delegation` 参数。

3. **方案 C：`wallet_sendCalls` 无 capabilities** — 最终采用。MetaMask 在 7702 兼容链上自动使用 type-4 交易，无需额外配置。
